# Development Guides

This directory maintains documents containing rules and guidelines that must be followed during development.

## Purpose

- Coding conventions and style guides
- Collaboration rules and workflow processes
- Best practices and patterns for the project

## Documents

| Document | Description |
|:---------|:------------|
| [coding-conventions.md](coding-conventions.md) | Formatting, linting, error handling, naming, comments |
| [testing.md](testing.md) | Test organisation, assertions, isolation patterns |

## Usage

- **Read first**: Always read the relevant guides before starting work
- **Follow strictly**: Guidelines in this directory must be followed during development
- **Keep updated**: Update guides when conventions or processes change

## File Naming

- Use descriptive names: `coding-style.md`, `git-workflow.md`
- Separate concerns into individual files
