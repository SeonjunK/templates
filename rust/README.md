# Rust Template

A general-purpose Rust project template.

## Structure

```
rust/
├── src/
│   └── lib.rs      # Library entry point
├── tests/          # Integration tests
└── Cargo.toml
```

## Commands

- Build: `cargo build`
- Test: `cargo test`
- Format: `cargo fmt`
- Lint: `cargo clippy`
