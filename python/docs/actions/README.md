# Action Documents

## Overview

Manages implementation items (Actions) derived from ADRs (Architecture Decision Records). Each Action is linked to GitHub repositories, Jira tickets, PRs, etc.

## Quick Reference

### Status Values

Action status
- ⏳ pending | 🔄 in-progress | ✅ done | ❌ cancelled | 🚫 blocked

External link status (Jira/PR)
- Each system uses its own status values (Jira: Open, Reopen, Holding, In Progress, Resolved, Closed / PR: Open, Draft, In Review, Approved, Merged, Closed)

### Action Types
- ✨ `feature` - New feature implementation
- 🐛 `bugfix` - Bug fix
- 🔧 `refactor` - Refactoring
- 📚 `docs` - Documentation writing/modification
- 🧪 `test` - Test code writing
- 🧹 `chore` - Miscellaneous tasks

### Priority
- 🔴 `critical` - Requires immediate attention
- 🟠 `high` - High priority
- 🟡 `medium` - Normal priority
- 🟢 `low` - Low priority
